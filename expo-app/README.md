## Echo Dashboard — Expo app (launcher)

Universal Expo app (Android + web) that will replace the Next.js PWA in the repository root. On the Echo Show 8 (LineageOS 18.1 / Android 11) it is installed as an APK and registered as the **home screen (launcher)**.

> **Status: skeleton.** Launcher, settings, device controls and the photo slideshow work. The full dashboard (weather, agenda) still lives in the Next.js app and will be migrated next.

### What works

- **Launcher**: declared as `HOME` in the Android manifest (via `android.intentFilters` in `app.json`); after install, press Home/choose "Echo Dashboard" as the default launcher
- **Emergency exit**: tap the **top-left corner 5 times within 3 seconds** to open the settings (the Echo Show has no navigation buttons)
- **Settings** (`src/app/settings.tsx`), stored on the device (`AsyncStorage`):
  - photo folder: MediaStore albums (= device folders with photos), via `expo-media-library`
  - brightness (system, needs the one-time `WRITE_SETTINGS` grant) and media volume
  - shortcuts to Android settings, Wi-Fi and "change default launcher"
- **Photo-slide** (`src/app/slideshow.tsx`): photos from the chosen folder with a 3s crossfade every 10s (`expo-image`, which decodes at screen size), small clock in the bottom-right corner; starts after 5 min idle or on demand; any touch goes back
- **Always on, immersive**: keep-awake, hidden status and navigation bars, landscape only

### Structure

```
src/
  app/          routes: _layout (fullscreen/keep-awake), index (home), slideshow, settings
  components/   Clock, SecretCorner
  hooks/        useClock, useSystemStatus (brightness, volume, Wi-Fi)
  lib/          photos (MediaStore), settings (AsyncStorage)
```

`android/` is generated by `expo prebuild` (Continuous Native Generation) and is not committed: configure native behavior in `app.json`.

### Build and install on the device

Requirements: JDK 17, Android SDK (`ANDROID_HOME`), `adb` with the device connected (`adb devices`).

```bash
npm install
# Release build (JS bundled, no dev server needed), arm64 only, installed via adb
ORG_GRADLE_PROJECT_reactNativeArchitectures=arm64-v8a \
  npx expo run:android --variant release --device <adb-serial>
```

Then press the Home button (or run `adb shell input keyevent KEYCODE_HOME`) and pick **Echo Dashboard → Always**.

To go back to the previous launcher: settings (5 taps) → "Trocar launcher padrão".

### Getting photos onto the device

The Echo Show has no SD card slot and little free storage (~3 GB user partition). Options:

- [Syncthing](https://syncthing.net/) syncing a folder from your PC/phone (new photos show up automatically)
- `adb push <folder> /sdcard/Pictures/<Name>/` followed by a media scan (or reboot)

Prefer photos resized to ~1920px wide: full camera files waste storage and decode time.

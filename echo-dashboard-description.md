# Short description (GitHub repo subtitle, max ~350 chars)

A universal Expo app that turns a jailbroken Echo Show 8 into a standalone smart dashboard. Runs as an Android launcher (fullscreen, landscape, photo slideshow from a device folder) or as a web app on Vercel. 24h clock, live weather via Open-Meteo, hourly/daily forecasts, weekly agenda, brightness/volume controls. TypeScript + Expo Router.
